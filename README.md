Sales Performance Dashboard

Project Overview
This project presents an interactive Sales Performance Dashboard built using Power BI.

Objectives
• Analyze Sales and Profit
• Monitor business performance
• Identify sales trends
• Enable interactive filtering using slicers

Tools Used
• Power BI
• Microsoft PowerPoint

Dashboard Features
• KPI Cards (Sales & Profit)
• Sales Trend Analysis
• Sales by Country
• Sales by Segment (Donut Chart)
• Country Filter
• Product Filter
• Date Filter

Key Insights
• Total Sales: 118.73M
• Total Profit: 16.89M
• Sales increased from 2013 to 2014
• United States contributed the highest sales
• Government segment contributed the largest share of revenue

Files Included
• Power BI Dashboard (.pbix)
• PowerPoint Summary (.pptx)
